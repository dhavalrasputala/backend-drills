## Day 2: Domain Name System (D.N.S)
- My Explanation

- A Client has to Visit tens of thoudsands of ip Address,ip Address in Raw form is very difficult to remember to solve this problem Domain Name System was introduced and it gives an I.P address an name thorough which you can access it.Hence making it easier for Client to remember and work with many i.p together.

## The Flow

- Client -> DNS -> IP Address -> Serve

## Trade-offs / Why it matters

- Helps Remember Thousand of I.P Address in Form of names hence reducing the friction between visiting the I.P and typing the Address for it.
