## Day 8: Caching Basics
- My Explanation

- In a computer system cache is an hardware componet that stores data for future use.this data might be the frequently used data or copy of data which was computed by the system.cache hit refers to retriving data stored from cache & cache hit refers to retriving data from disk storage rather then cache.

## The Flow

-  Server --> Cache(Miss) --> DB --> Storage --> Client.
