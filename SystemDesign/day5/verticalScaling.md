## Day 5: Vertical Scaling 
- My Explanation

- With increase in the number of users , load on server also increase to handle this load server has two option Horizontal Scaling & Vertical Scaling.

- Vertical Scaling refers to process of increasing capabilites of available hardware instead of spending money on buying more hardware. 

## The Flow

- mysql server runs on 16GB RAM --> Upgrading it to 64GB RAM for handling more queries 

## Trade-offs / Why it matters

- Not every server needs to more hardware according to thier business goals.

- Horizontal scaling is often time more expensive then vertical scaling and overkill for many systems.
